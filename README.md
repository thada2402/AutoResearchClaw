## ⚙️ What is AutoResearchClaw?

AutoResearchClaw is a tool that takes your research idea and creates a draft paper. It uses smart technology to find relevant information, check citations, and build a well-structured draft. You do not need to write or verify facts—you only give your idea.

The software is designed for people who want a smooth research process. It can:

- Convert an idea into a written paper outline.
- Verify citations for accuracy.
- Organize research into sections.
- Update and improve the paper over time.

It is self-contained. You use it by downloading the app and running it. No extra installation or technical steps needed.

Here is how to start using the software once installed:

## 📂 File Locations and Data Storage

AutoResearchClaw saves project data in a folder inside your Documents directory called `AutoResearchClawProjects`.

- Each idea and paper is saved as its own folder.
- Draft text is stored as plain files editable outside the app.
- Citation reports are saved alongside paper drafts.
  
You can back up this folder or move it if needed. The app will still work as long as you keep the files in one place.

## 🛡️ Privacy and Data Handling

AutoResearchClaw only sends what is needed to connected services for citation checking. Your ideas and drafts stay private on your PC by default. Information sharing happens only when you ask for paper verification or external data retrieval.

You can use the app offline for drafting, but some features will be limited without internet access.
